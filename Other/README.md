# Object Modeling & Class Architecture (Python)

**Project Period:** February - March 2026

## Project Overview

This project explores object-oriented programming (OOP) principles in Python by modeling real-world entities using publicly available datasets. The effort focuses on translating structured data into object-oriented representations while strengthening software design and architecture skills.

Key goals include:

* Developing proficiency in Python class design
* Modeling logical entities and their relationships
* Converting raw datasets into structured object models
* Comparing design and abstraction approaches across team members
* Applying OOP concepts to real-world geographic and maritime datasets

---

## Objectives

### 1. Object Modeling & Architecture

* Design Python classes representing real-world entities
* Define attributes, behaviors, and relationships
* Establish logical boundaries between objects
* Transform raw datasets into instantiated class objects
* Develop scalable and maintainable class architectures

### 2. Entity & Relationship Modeling

* Identify primary and secondary entities within datasets
* Model relationships between entities and assets
* Represent real-world interactions through object-oriented structures

Example relationships:

* Cargo ↔ Carrier
* Vessel ↔ Maritime Asset
* Person ↔ Handler ↔ Asset
* Infrastructure ↔ Geographic Location

### 3. Comparative Design Exercise

* Compare modeling approaches among team members
* Evaluate architectural and abstraction decisions
* Assess tradeoffs between simplicity, flexibility, and scalability
* Explore multiple methods for representing similar datasets

## Data Strategy

### Potential Data Sources

Publicly available datasets, including:

* Data.gov
* Government infrastructure datasets
* Maritime and vessel databases
* Geographic and mapping datasets
* Public asset inventories

### Dataset Selection Criteria

Preferred datasets should:

* Contain large-scale records (target: >1 million entries)
* Include detailed attributes and metadata
* Support complex entity relationships
* Enable realistic object modeling scenarios

### Preliminary Data Analysis

Prior to class development, datasets will be analyzed to:

* Understand relationships between data elements
* Identify logical entity boundaries
* Determine object ownership and dependencies
* Inform class architecture and design decisions
